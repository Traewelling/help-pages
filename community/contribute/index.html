    Mitentwickeln

    Träwelling ist Open Source, jede*r kann mitmachen.

    Der Code und alles Weitere liegen in unserem GitHub-Repository.

    Du kannst:

    • eigene Ideen umsetzen,
    • dir Aufgaben aus unseren Issues raussuchen,
    • oder einfach einen Pull Request erstellen.

    Wir freuen uns über jeden Beitrag, egal wie klein oder groß.

    An Träwelling arbeiten seit 2013 viele Menschen mit, mal mit kleinen Bugfixes, mal mit großen Features. Die Liste der Beitragenden findest du auf GitHub. Wer uns bei der Alpha-Version unterstützt hat, steht in der humans.txt.
