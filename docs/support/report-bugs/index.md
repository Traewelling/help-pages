---
title: "Fehler melden"
---

**TL;DR:** Fehler bitte als Issue auf [GitHub](https://github.com/Traewelling/traewelling/issues) melden und vorher kurz schauen, ob der Bug schon gemeldet wurde.

---

So gehst du vor:

1. Wirf einen Blick in die [Liste an gemeldeten Fehlern](https://github.com/Traewelling/traewelling/issues). Sie ist
   öffentlich einsehbar, so vermeidest du eine doppelte Meldung.
2. Ist dein Fehler noch nicht dabei, klicke im [GitHub-Repository von Träwelling](https://github.com/Traewelling/traewelling/issues)
   auf „New issue“.
3. Wähle „Bug report“ aus.
4. Fülle das Formular aus und beschreibe den Fehler so detailliert wie möglich:
    - Was du gemacht hast
    - Was du erwartet hast
    - Was stattdessen passiert ist
    - Und am besten: Wie wir den Fehler nachstellen können
5. Klicke auf „Submit new issue“.

Bitte erstelle das Issue nach Möglichkeit auf Englisch, so kann die ganze Community mitlesen und mithelfen.
Auf Deutsch ist aber auch völlig okay, lieber eine deutsche Meldung als gar keine.
