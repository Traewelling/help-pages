---
title: "Report a bug"
---

**TL;DR:** Please report bugs as an issue on [GitHub](https://github.com/Traewelling/traewelling/issues), and check first whether the bug has already been reported.

---

This is how it works:

1. Have a look at the [list of reported bugs](https://github.com/Traewelling/traewelling/issues). It is publicly
   visible, so you can avoid reporting something twice.
2. If your bug is not in there yet, go to the [Träwelling GitHub repository](https://github.com/Traewelling/traewelling/issues)
   and click on "New issue".
3. Select "Bug report".
4. Fill in the form and describe the bug in as much detail as possible:
    - What you did
    - What you expected to happen
    - What happened instead
    - Ideally: How we can reproduce the error
5. Click on "Submit new issue".
